One-line out-of-office auto-reply for make.fun's "The Funniest Out-of-Office" bounty: an auto-reply that delegates the sender's email to the one person least likely to answer it — its own author, twice as slowly.

## Run it

```sh
node main.ts
```

Writes the entry text to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). Node 22+ stdlib only, no dependencies.
